# 项目科学介绍（Project Scientific Overview）

**项目名称**：dit-ad-classifier — 基于 AFQ 白质剖面图谱的多中心阿尔茨海默病判别可复现基线
**文档性质**：项目级科学介绍（面向合作者、竞赛组织方与评审者；工程细节见 `USAGE.md`，评估协议见 `FROZEN_EXPERIMENT_SPEC.md`）
**版本**：dit v0.2.0 ｜ 2026-11-20

---

## 1. 项目摘要

本仓库实现并系统验证了一套**面向多中心弥散张量成像（DTI）白质剖面数据**的阿尔茨海默病
（AD）判别流水线。系统以 AFQ（Automated Fiber Quantification）提取的 18 条白质纤维束
× 100 节点 × 8 项弥散指标（每受试者 14,400 维）为输入，在严格的无泄漏交叉验证框架下
完成 NC/MCI/AD 三分类与 NC/AD 二分类判别，并提供从评测、概率校准到部署工件的完整闭环。

本项目的核心主张不是某个单一模型，而是一套**可审计的实验方法学**：

1. **一切学习型变换（插补、缩放、协变量残差化、特征选择、超参搜索、概率校准）只在
   外层训练折内拟合**，测试折仅继承冻结参数；
2. **主性能指标只来自外层折 Out-Of-Fold（OOF）argmax**；自适应决策阈值作为部署策略
   单独寻优、单独标注，其同集得分永不作为性能呈现；
3. **年龄是最强混杂因素**，因此协变量策略（none / feature / residualize）与阴性对照
   （纯人口学、纯追踪缺失率）与影像视图走完全相同的折与指标，使"模型学到的是病理
   还是年龄/采集伪影"成为可量化的实验问题；
4. **跨中心泛化是一等公民**：留一中心（LOSO）轨道测量零样本域迁移下界，配对统计
   附带 5 折功效下界的显式警示。

## 2. 背景与科学动机

### 2.1 白质微结构与阿尔茨海默病

AD 的经典影像标志（海马萎缩、皮层变薄）之外，越来越多的证据表明白质纤维束的微结构
完整性（以 FA、MD、RD、AxD 表征）与认知衰退相关。AFQ 方法学（Yeatman et al., 2012，
PLoS ONE）的关键贡献在于**tract profile**：沿每条纤维束等距采样的 100 个节点各自测量
组织特性。相比束均值，剖面图谱保留了"损伤发生在束的哪个节段"这一空间信息——而疾病
往往恰恰打击特定节段。这使节点级特征既有生物学动机，也有更高的判别信息量。

### 2.2 多中心数据的双重挑战

AI4AD 竞赛数据来自多个采集中心，带来两个统计难题：

- **维度灾难**：每受试者 14,400 维特征 vs 约 700 受试者（p/n ≈ 20），必须依赖正则化
  与结构化的特征选择；
- **中心漂移**：不同中心的扫描仪硬件与序列参数造成系统性域偏移，混合分布内的高准确率
  可能只是记住了中心指纹。LOSO（留一中心）是测量真实泛化下界的标准设计。

### 2.3 人口学混杂

AD 受试者系统性地年长于对照。若不处理年龄，分类器可能学到"年龄"而非"白质病理"。
本系统将此作为一等科学问题处理：三种协变量策略并行报告，其差距本身就是结果。

## 3. 科学问题与可证伪假设

本项目的实验设计围绕三个可证伪假设组织：

| # | 假设 | 实验设计 | 判定方式 |
|---|---|---|---|
| H1 | 白质剖面携带超越人口学的疾病信号 | 影像视图 vs `demographics` 阴性对照（同折同指标） | 影像显著优于纯人口学，且 residualize 策略下仍保持 |
| H2 | 判别信号不是采集伪影 | 影像视图 vs `missingness` 阴性对照 | 影像显著优于纯缺失率视图 |
| H3 | 存在可用的跨中心泛化 | Track B（LOSO 7 折）vs Track A（stratified 5 折） | LOSO 平衡准确率及其逐中心分解、最差中心表现 |

每个假设的判定都通过 `ablation`/`matrix` 命令的预声明消融矩阵执行，配对比较仅允许在
折结构完全匹配（fold ID + test_index_digest）的结果间进行（见 §5.6）。

## 4. 数据

**AI4AD 多中心 DTI 数据库**（Qu et al., 2021, *Brain Disorders*）：多中心采集的 DTI
数据，AFQ 处理后形成每受试者 [18 纤维束 × 100 节点 × 8 弥散指标] 的剖面张量，临床
标签为 NC / MCI / AD 三分类。

**数据状态（声明边界）**：真实 `.mat` 数据由竞赛组织方按其数据访问协议分发，**不在
本仓库内**。本仓库的全部开发验证使用内置的确定性合成数据（`dit.data.synthetic`），
因此本仓库内外出现的任何性能数字均为**流水线验证，不是临床结果**。真实数据获取后，
本文件 §3 的全部实验设计可直接执行，无需修改代码。

## 5. 方法学

### 5.1 显式数据契约

数据在 `DatasetBundle`（`dit/data/schema.py`）中以显式数学契约承载并在构造期强制校验：
4 维非零轴张量、官方标签 1/2/3 → canonical 0/1/2 的受控重编号（二分类视图重编号为
0=NC / 1=AD 并由 view.label_map 命名）、整数站点编码（拒绝 NaN 与 -1 缺失去切分）、
缺失值以 NaN/mask 显式表达。契约的存在使"标签错位"这类灾难性 bug 在入口即被拒绝——
2026-11-19 的审计确实在入口抓到了一个会使二分类静默丢光对照组的此类缺陷（见
`AUDIT_2026-11-19.md` P1-1/P1-2）。

### 5.2 双轨评估协议

依据 `FROZEN_EXPERIMENT_SPEC.md`（生效冻结版）：

- **轨道 A（竞赛基准复现）**：stratified 5 折，主指标为外层 OOF argmax 准确率；
- **轨道 B（多中心域泛化）**：LOSO 7 折，主指标为 pooled OOF 平衡准确率，逐中心分解；
- **探索轨（站点均衡折）**：site-stratified 5 折，仅作鲁棒性附表。

两轨测量不同的泛化误差，严禁合并为单一分数。内层调优按轨道分别采用类分层或站点
整留出验证。

### 5.3 防泄漏纪律

插补（中位数）、标准化、协变量 OLS 残差化、块/节点级特征选择、超参网格搜索、概率
校准全部位于 sklearn Pipeline 内、由 GridSearchCV 在**每个内层折重新拟合**；外层测试
折只继承训练折冻结的参数。审计对每条变换核对了"拟合域/转换域"并留下了对应的回归
测试（选择器的逐内折重拟合由 spy 测试钉住）。

### 5.4 协变量策略与阴性对照

| 策略 | 含义 | 科学用途 |
|---|---|---|
| `none` | 完全剔除人口学 | 疾病信号上界 |
| `feature` | 年龄/性别作为普通特征 | 默认基线 |
| `residualize` | 折内 OLS 残差化 | 白质结构信号（去人口学） |
| `demographics`（阴性对照） | 仅 [age, sex] | H1 判定 |
| `missingness`（阴性对照） | 各束追踪失败率 | H2 判定 |

### 5.5 模型体系

- **经典路径**：linear SVM（Platt 校准）、弹性网 logistic、随机森林、直方图梯度提升，
  均封装于折内流水线；profile 视图（14,400 维）下由 L1 弹性网系数幅值做块/节点两级
  选择。
- **深度路径**：Tract-Transformer 将 18 条纤维束作为 18 个解剖 Token，保留束间关系建模，
  支持 CORAL / MMD / DANN 三种域对齐损失与温度/多元 Sigmoid 概率校准（校准行独立于
  训练行与早停行）。
- **集成路径**：以内层折平衡准确率为权重的软投票，权重按折重算并显式发布。

### 5.6 评估与不确定性量化

- **主指标**：外层折 OOF argmax 的 accuracy / balanced accuracy / macro-F1 / ROC-AUC；
  二分类附敏感度/特异度（仅对二分类任务视图发射，多分类缺类折不得沿用该命名）。
- **阈值策略**：基于 OOF 分布的坐标下降寻优是**部署策略**；其同集得分被显式标注为
  selection-set 诊断，报告层面与性能指标物理隔离。
- **配对统计**：Wilcoxon 符号秩检验仅对折结构完全匹配（fold ID + test-index digest +
  任务 + 策略 + 类别计数 + 数据快照摘要）的结果开放；5 折下双侧最小可达 p 值为 0.0625，
  报告自动携带该功效警示。
- **校准评估**：ECE 与 Brier 分数随报告输出；温度缩放附带"搜索是否触界"标记，使被截断
  的拟合值与真实拟合值可区分。

### 5.7 部署闭环

`fit` 在全量有标签数据上执行与评测相同的折内搜索，序列化为带 SHA-256 侧车的工件；
`predict` 先验签再反序列化，校验特征列契约（含残差化路径的列宽特例）与概率合法性，
输出提交用 CSV。工件加载对全部必需段的缺失/损坏一律给出带路径的可操作错误。

## 6. 可复现性工程

| 机制 | 说明 |
|---|---|
| 确定性 | 全链路固定种子；合成数据、分割、训练同种子逐位复现 |
| 溯源 | 每折携带非标识性 manifest（test-index SHA-256、类别计数、数据快照摘要） |
| 严格序列化 | 报告 JSON 强制 allow_nan=False，非有限值显式转 null 并附语义文档 |
| 数据获取 | `fetch` 子命令的 SSRF 防护（scheme/端口白名单、逐跳重验、socket 地址钉扎） |
| 测试 | 689 个自动化测试（合成数据、无网络依赖），CI 双矩阵（no-torch / torch CPU） |
| 许可 | MIT；仓库不含任何受试者数据 |

## 7. 当前状态与声明边界

1. **无真实数据**：AI4AD `.mat` 需向组织方申请；截至本文档，全部运行均为合成数据上的
   流水线验证。**本仓库不存在任何临床性能声明。**
2. **竞赛计分规则**：以 Macro-F1 与宏平均 ROC-AUC 为主报告指标是对竞赛设置的推断，
   组织方细则以最终说明为准。
3. **文献区间**：interpret 的文献区域对照表中，扣带回节点区间存在代码（1–10）与文档
   （40–60）的矛盾且两轮外部检索均无可核验来源；代码保持现状并已在文档中标注待证，
   取得可引用来源前该区段命中结论不作为证据。
4. **方法学验证**：上述 §5 的全部纪律均有对应回归测试与六轮独立复审记录（见
   `REVIEW_METHODOLOGY.md`）。

## 8. 局限与后续工作

- 真实数据上的完整实验矩阵（§3）待数据获取后执行；
- 5 折配对检验的统计功效下界（p ≥ 0.0625）是固有约束，需要更大折数或外部测试集才能
  获得更精细的显著性判定；
- fold 报告的 TypedDict 化、sklearn 收敛警告门控等待迭代项列于修复记录 §4 未决清单。
