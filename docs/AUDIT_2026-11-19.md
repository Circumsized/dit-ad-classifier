## 5. P1 详述（含复现证据）

### P1-1：canonical 编码文件的类别名错位

`canonicalize_labels` 明确接受 0/1/2 输入（raw==canonical 恒等映射），但
mat_loader 用官方表 `LABEL_NAMES[raw]` 反查：raw=1 → "NC"（实为 MCI）、
raw=2 → "MCI"（实为 AD）。复现（venv 探针）：

```
raw_label_map: {0:0, 1:1, 2:2}
derived class_labels: {1:'NC', 2:'MCI'}     # 期望 {0:'NC',1:'MCI',2:'AD'}
label_map: {0:'NC', 1:'NC', 2:'MCI'}        # 两个 'NC'，AD 消失
_label_for(NC): 1  _label_for(AD): 2       # NC 解析到 MCI
binary kept labels: [0, 1]  n=8 of 12       # 丢光真 NC，留下 MCI+AD
binary class_names: ('NC', 'AD')            # 却报告 NC-vs-AD
```

修复：`raw_label_names()` 按 raw 键域选表（official ⊆{1,2,3} → 官方表；
否则 canonical 表），11 种合法 raw 域逐一测试钉住。

### P1-2：未命名二值源的静默单类视图

`_label_for("AD")` 经全局表回退返回 2（不存在于 y={0,1}），`task_view` 守卫
只查 None。修复：只在视图标签集内解析；`reference == disease` 一并拒绝；
11 种 raw 域 + 未命名组合全部有测试。

### P1-3：元数据缺失的静默降级

MAT 无 population/site 键时协变量全 NaN（feature 策略静默变 none）、站点
全 -1（站点分析静默消失），`summary()` 无任何字段可揭示。修复：
`demographics_available`/`site_available`/`n_missing_site` 进入 summary；
CLI 跳过站点分析时写显式 note。

### P1-4：测试凹陷

四类关键路径无测试钉住（配对拒绝分支、主路径 OOF 口径、选择器折内拟合、
interpret/），任何回归都会静默通过 525 个测试。修复：新增 120+ 个生产路径
用例，关键项经变异实测杀死。
